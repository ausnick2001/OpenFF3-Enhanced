Fonts that come with OpenFF
===========================

Each is free to use and to pass on. OpenFF reads them from the folders below; to use a font of
your own instead, put it in the same folder with a name that sorts first (the first font in a
folder by file name is the one drawn), or take ours out. See README.txt.

menus\FFFontrecreation.ttf   FF Font recreated ("FF Modern Font Recreation")
    A fan-made recreation in the style of modern Final Fantasy menu lettering.
    Author and licence: <TO FILL IN BEFORE RELEASE: name, and the licence it was published under>

names\Ferrum.otf             Ferrum, version 0.200
    By Sora Sagano (dot colon). CC0 1.0 - public domain, no rights reserved.
    http://creativecommons.org/publicdomain/zero/1.0/

dialogue\DialogueFont.otf   a generic video-game dialogue face
    Author and licence: <TO FILL IN BEFORE RELEASE: the font's real name, its author, and the licence it was published under>
    dialogue\scale.txt (0.75) sets its size; see README.txt.

fonts\title is left empty. The title screen keeps the game's own face (Windows' Times New Roman); any font put there is used
instead.
