# OpenFF3 Enhanced

An enhanced version of **Final Fantasy III** (3D remake) on PC in OpenFF . It runs from your own Steam or GOG copy as a native desktop game, and adds the things I always wanted while playing it. Full list of features and release coming soon.

This is built on [zerratar's OpenFF](https://github.com/zerratar/openff), which did the hard work of getting FF3 3Ds code decompiled. If you like what's here, go and give that project some love too.
